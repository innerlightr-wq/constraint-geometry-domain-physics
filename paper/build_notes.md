# Build Notes

## Compiling

The manuscript is a single self-contained LaTeX file with an embedded bibliography. No BibTeX or Biber run is required.

```
pdflatex constraint_geometry_domain_physics.tex
pdflatex constraint_geometry_domain_physics.tex
```

Two passes are needed so that the table of contents, cross-references, and equation references resolve. Equivalently:

```
latexmk -pdf constraint_geometry_domain_physics.tex
```

## Required packages

- `amsmath`, `amssymb`, `amsthm` — mathematics and theorem environments
- `mathtools` — display refinements
- `booktabs` — the comparison tables
- `geometry` — 1 inch margins
- `enumitem` — labelled list formats (the non-claims and protocol lists)
- `hyperref` — internal links and DOI links, loaded with `hidelinks`

Two packages are loaded conditionally with `\IfFileExists`, so the document compiles in minimal TeX installations that lack them:

- `lmodern` — scalable Latin Modern fonts
- `microtype` — loaded with `expansion=false`, which is required when only bitmap fonts are available

## Computation

There is no computational pipeline. All equations in the paper are analytic, and all numerical values quoted are roots of stated polynomials or elementary arithmetic on values attributed to cited sources. Nothing needs to be run to reproduce the manuscript.

## Figures

The SVG figures in `figures/` are repository documentation, not empirical outputs. They are not included in the compiled PDF and are not generated by any script. They are hand-written SVG so that they can be edited directly.
