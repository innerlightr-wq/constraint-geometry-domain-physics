# Non-Claims

This page exists because the framework is easy to overread. The partition geometry recurs across domains, and recurrence invites the inference that something universal has been found. The note's position is the opposite: recurrence is expected, and by itself uninformative.

## What is not claimed

The framework does **not** claim:

1. **To derive the Einstein field equations.** The uniqueness of $G_{\mu\nu}+\Lambda g_{\mu\nu}$ among divergence-free second-order symmetric tensors is a separate result with a separate proof. The partition enters only after an exact rearrangement of a field equation that is taken as given.
2. **To derive ΛCDM.** The cosmological flow identities are standard logistic-flow calculus written in partition coordinates.
3. **That the intrinsic cubic is a universal law of gravity,** a fundamental constant of nature, or a universal physical phase transition.
4. **That nonlinear gravity begins suddenly at $C_{*}$.** The higher-order sector of the Einstein tensor is nonzero for every $C>0$ and grows smoothly; no onset is asserted.
5. **That post-Newtonian accuracy degrades at $C_{*}$.** The literature supports a qualitative loss of accuracy as a binary approaches merger. It attaches no numerical compactness threshold, and neither does this note. The quantity governing post-Newtonian accuracy is also not the same quantity as the structural compactness used here.
6. **That similar partition geometry implies identical dynamics.** Two systems can share the response-boundary class while occupying entirely different dynamical classes.
7. **That an intrinsic landmark has physical meaning before an independently justified embedding.** A landmark is a locus in partition space. Meaning arrives, if at all, with the map.
8. **That reparameterizing one scalar state adds information.** If every partition coordinate is an invertible function of a single domain quantity, they reorganize the same information and create no new predictive degree of freedom.
9. **That numerical proximity alone constitutes evidence.** A landmark is only as informative as its neighbourhood is sparse.
10. **That the examples in the paper constitute empirical validation.** They are illustrations chosen to show how the architecture separates cases, including cases where it returns a negative.

## What the framework does provide

- **A common constrained state space.** The conserved binary partition, with its boundary structure and its bounded/unbounded coordinate split.
- **A coordinate vocabulary.** Bounded, hyperbolic, and response descriptions of the same state, with explicit translations, so that apparent conflicts between descriptions can be identified as such.
- **Intrinsic relational landmarks.** Exactly located loci fixed by the constraint alone, available for testing in any domain that supplies a genuine partition.
- **A method for separating geometric structure from domain interpretation.** Three objects kept apart: the intrinsic marker, the domain embedding, the physical interpretation.
- **A protocol for testing whether a partition-based diagnostic is physically meaningful,** including the safeguard that an arbitrary embedding can manufacture any desired threshold.

## The load-bearing sentence

> A physical diagnostic emerges only where constraint geometry and domain physics intersect under an independently justified map.

Everything in [`docs/protocol.md`](docs/protocol.md) and [`docs/safeguards.md`](docs/safeguards.md) is machinery for enforcing that sentence.
